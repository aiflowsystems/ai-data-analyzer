\# AI Data Analyzer



An AI-powered business analytics tool that reads sales data from a CSV file, calculates key performance metrics, and generates actionable business insights using OpenAI.



\## Features



\- Read sales data from CSV files

\- Calculate total revenue

\- Identify the best-selling product

\- Calculate average revenue per product

\- Generate AI-powered business insights

\- Create professional business reports automatically

\- Combine data analysis with AI interpretation



\## Technologies Used



\- Python

\- OpenAI API

\- CSV Processing

\- Data Analysis

\- Business Metrics

\- File Handling

\- AI Report Generation



\## Workflow



1\. Read sales data from `sales.csv`

2\. Calculate revenue for each product

3\. Calculate total revenue

4\. Identify the best-selling product

5\. Calculate average revenue per product

6\. Generate a structured sales report

7\. Send metrics to OpenAI for analysis

8\. Generate business insights and recommendations

9\. Save the final report



\## Example Input



```csv

product,quantity,price

Laptop,5,1000

Mouse,20,25

Keyboard,10,50

Monitor,8,300

```

